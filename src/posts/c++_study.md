### 格式化输出

1. 首先加上头文件`iomanip`
2. 内容很多，可以查表看函数，默认浮点数的有效位数是6位，可以通过函数调整，例如

``` c++
double x = 123.456789;

cout << setprecision(9) << x; // 输出 123.456789
```

### 函数拓展

1. 内联函数：`inline`置于函数定义句首，可以在预处理时，将整个函数内嵌到源代码中，以免出现频繁使用某个函数时，底层内存pc多次跳转。
inline只是对编译器的建议，如果函数循环多，编译器也会自己决定不选择inline
2. 函数重载：同一函数名定义不同版本的函数。不同版本指，参数个数，或者类型不同。
3. 函数模板：函数逻辑同，只是数据类型不同。
``` c++
template <typename T>
T max(T a, T b, T c) {
    // 函数体
}
```
T是虚拟类型，调用时，真是的参数类型会替代T
4. 默认参数：在定义函数时给形参默认值。如果调用时没有给这个参数的值，那么就用默认值
默认参数必须放在参数列表最右边。
``` c++
void f(int a = 1, int b, int c = 3); // 不合法
void f(int a, int b = 2, int c = 3); // 合法
```

### const常量

1. 指向常量的指针
``` c++
const int *p;
int const *p;
```
两种写法都相当于“南瓜套”，保护内部的植物。不过南瓜套可以取下来放在不同的地方。
2. 常指针
``` c++
int * const p=&a;
```
p不能改变指向的内存，但是内容可以改
3. 指向常量的常指针
``` c++
const int * const p=&a;
```
p指向不变，内容也不能变
