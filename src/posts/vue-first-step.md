学 Vue 之前，我连 HTML 都不太熟。没想到配好 Vite 之后，保存代码就能立刻在浏览器里看到效果，这种"所见即所得"的反馈太让人上瘾了。

## 第一个组件

我用 Vue 写了一个会跟着鼠标转眼珠的小人，点击它的脑袋还能像开盖子一样展开成一张博客卡片。

虽然它一开始长得有点丑，但慢慢调整颜色、圆角、动画曲线之后，竟然变得有点可爱了。

## 收获

- 理解了响应式数据 `ref`
- 学会了 `@click` 事件绑定
- 第一次用 CSS 变量做主题色

继续加油！
